## 🇬🇧 English

### 👋 About me

I design and build connected digital experiences around immersive fictional universes.

As **Project Lead & Developer at Immersive Studio**, I work across project direction, product design, specifications, development, testing, deployment, release management and technical coordination. My projects combine Minecraft Java, web platforms, Discord systems, Windows applications and self-hosted infrastructure.

> I do not just imagine universes — I build the systems that make them playable.

### 🚀 Featured projects

| Project | Description | My role |
|---|---|---|
| **[Immersive Studio](https://immersive-studio.fr/)** | A creative and technical hub bringing together Minecraft, roleplay and interactive-universe projects. | Project leadership, product vision, organization, web presence and technical coordination. |
| **[L’Héritage de Poudlard](https://heritagedepoudlard.fr/)** | A French Minecraft RP ecosystem with a custom world, gameplay systems, website, player and staff portals, Discord integration, launcher and modpack. | Creator and project lead; systems design, specifications, development, infrastructure, testing and releases. |
| **[Héritage Launcher](https://github.com/Immersive-Studio-Corporation/heritage-launcher)** | A custom Windows launcher with Microsoft authentication, Java and Minecraft preparation, modpack updates, access requests, skins and staff tools. | Product design, development, testing, release management and maintenance. |
| **[Licaris Launcher](https://github.com/Immersive-Studio-Corporation/licaris)** | A Windows launcher for a Cobblemon experience, with automatic updates, verified modpack management, skins, shaders and player customization. | Development, product design, testing, release automation and maintenance. |
| **Familier Fantastique** | A Discord companion game with exploration, energy, inventory, achievements, rankings, events and multi-familiar progression. | Concept, gameplay design, product direction, infrastructure and technical coordination. |

Other Immersive Studio universes currently being explored include **Teen Wolf, Avengers, The Last of Us, Zelda** and **NewGen**.

### 🧩 What I build

- Minecraft Java mods across multiple mod loaders, plugins, server tools and custom gameplay systems
- Custom launchers, modpacks, update pipelines and Microsoft/Minecraft authentication flows
- Web platforms, player portals, application forms and administration panels
- Discord bots, Activities, OAuth integrations, notifications and role synchronization
- Windows desktop applications, installers and automatic update systems
- REST APIs, PostgreSQL databases, Docker services and Linux infrastructure
- Blockbench models, creatures, wands, trains, custom entities, textures and interactive content
- Project specifications, testing workflows, release processes and technical documentation

## 🇫🇷 Français

### 👋 À propos de moi

Je conçois et développe des expériences numériques connectées autour d’univers fictifs immersifs.

En tant que **chef de projet et développeur chez Immersive Studio**, j’interviens sur la direction de projet, la conception produit, les spécifications, le développement, les tests, le déploiement, la gestion des versions et la coordination technique. Mes projets réunissent Minecraft Java, plateformes web, systèmes Discord, applications Windows et infrastructure auto-hébergée.

> Je ne me contente pas d’imaginer des univers : je construis les systèmes qui permettent de les vivre.
