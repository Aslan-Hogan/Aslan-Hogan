## 🇬🇧 English

### 👋 About me

I design and build connected digital experiences around immersive fictional universes.

As **Project Lead & Developer at Immersive Studio**, I work across project direction, product design, development, testing, deployment and technical coordination. My projects combine Minecraft, web platforms, Discord systems, Windows applications and infrastructure.

> I do not just imagine universes — I build the systems that make them playable.

### 🚀 Featured projects

| Project | Description | My role |
|---|---|---|
| **[Immersive Studio](https://immersive-studio.fr/)** | A creative and technical hub bringing together immersive roleplay and Minecraft projects. | Project leadership, product vision, organization, web presence and technical coordination. |
| **[L’Héritage de Poudlard](https://heritagedepoudlard.fr/)** | A French Minecraft RP ecosystem with a custom world, gameplay systems, website, player portal and Discord integration. | Creator and project lead; systems design, specifications, development, infrastructure and releases. |
| **[Licaris](https://github.com/Immersive-Studio-Corporation/licaris)** | A Windows launcher for a Cobblemon experience, with automatic updates, modpack management and player customization. | Development, product design, testing, release automation and maintenance. |
| **Familier Fantastique** | A Discord companion game with exploration, energy, inventory, achievements and multi-familiar progression. | Concept, gameplay design, product direction and technical coordination. |

### 🧩 What I build

- Minecraft experiences, custom gameplay systems and modded environments
- Web platforms, player portals and administration panels
- Discord applications, OAuth integrations and role synchronization
- Windows launchers, installers and automatic update systems
- PostgreSQL databases, APIs, Docker services and Linux infrastructure
- Blockbench models, custom creatures, wands and interactive entities
